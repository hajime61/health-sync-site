プライバシーポリシー

最終更新日: 2026年9月20日

Health Sync（以下「本アプリ」）は、作成者本人が自身の健康データを記録するために 利用する個人用スクリプトです。本ポリシーは、本アプリが Google ユーザーデータを どのように扱うかを説明します。

1. 取得する情報

本アプリは、利用者が明示的に許可した場合にのみ、Google Health API を通じて 以下のデータを読み取ります。いずれも読み取り専用です。

  • 活動量データ（歩数、距離、消費カロリー、活動時間）
  • 心拍データ（心拍数、安静時心拍、心拍変動）
  • 睡眠データ（睡眠時間、睡眠ステージ）
  • 身体測定値（体重、体脂肪率）
  • 栄養・水分摂取の記録

2. 利用目的

取得したデータは、利用者本人が所有する Google スプレッドシートに記録し、 利用者自身が健康状態および生活習慣の推移を把握する目的でのみ使用します。

3. 保存場所

データは利用者本人の Google アカウント内のスプレッドシートにのみ保存されます。 本アプリの作成者が管理する外部サーバーやデータベースは存在しません。

4. 第三者への提供

本アプリは、取得したデータを第三者に送信、共有、販売することは一切ありません。 広告目的での利用、および分析目的での外部サービスへの送信も行いません。

5. Google ユーザーデータの取り扱い

本アプリによる Google API から取得した情報の使用は、 Google API サービスのユーザーデータに関するポリシー （限定的使用に関する要件を含む）に準拠します。

6. データの削除

利用者は、 Google アカウントの権限設定 からいつでも本アプリのアクセス権を取り消せます。スプレッドシートに記録済みの データは、利用者自身がスプレッドシートを削除することで完全に消去されます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、Google Cloud コンソールに登録された サポートメールアドレスまでご連絡ください。
